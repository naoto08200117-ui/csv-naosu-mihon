CSV を直す道具

Excel で開くと「文字化けする」「頭の0が消える」「品番が日付に変わる」CSV を、崩れない形で保存し直します。

1. CSV を選ぶ

ここに CSV ファイルを置く（またはクリックして選ぶ） ファイルを枠の上まで引っぱって離すか、枠をクリックして選びます（1つずつ）
試すための架空の CSV：文字化け用・頭の0用・日付用

ファイルはこのパソコンの中だけで読み込みます。インターネットには送りません。

2. 直す内容を確かめる

    「Excel で開く用」は、守る値を ="0123" の形で書きます。Excel では 0123 と表示されますが、ほかのシステムに取り込むと記号が残るので、その場合は下の形を選んでください。

    守る列（チェックを外すと、その列はそのままにします）

    3. 直す前と後

    赤：そのまま Excel で開くと崩れる値　黄：直した CSV を Excel で開いたときに、書いたまま見える値（上から30行まで表示）

    直す前（Excel で開くと崩れる所）
    直した後（黄＝守った値。赤のままの値は、Excel で開くと崩れます）

    4. 保存する

    この道具がすること・しないこと

    • 文字コード：UTF-8 と Shift_JIS を見分けて読み、Excel が正しく読める形（UTF-8・先頭に目印の BOM 付き）で保存します
    • 頭の0：0600001 のように0で始まる数字、12けた以上の数字（JAN コードなど）を守ります
    • 日付に化ける値：1-2・3/4・12月3日 のように、年のない値を書いたままに守ります（2026-10-01 のような年のある日付は、Excel で日付として使えるよう、そのままにします）
    • 読めるのは UTF-8 と Shift_JIS の CSV です（それ以外は正しく読めません）。画面で見比べられるのは上から30行まで、ファイルは 20MB までです
    • 1行目は見出しとして扱い、そのままにします
    • しないこと：中身の書きかえ（全角・半角をそろえる、重複を消すなど）。保存する前に、直す前と後を必ず見比べてください
